


# Simple Matrimony System – Java Console Application (Arrays Only)

A beginner-friendly Java matrimony application built using **arrays instead of collections**.
This project showcases strong understanding of **core Java, OOP concepts, arrays, and console-based programming**.


##  Features
###  Profile Registration
Stores candidate details such as:
* Name
* Age
* Gender
* Profession
* City
* Preferred Match City

###  View All Profiles
Displays all registered profiles stored inside a fixed-size array.

###  Matchmaking Logic
Provides matches based on:
* Opposite gender
* Age difference (≤ 5 years)
* Preferred city match
